# NutriTrack - Daily Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracking web application built entirely with vanilla HTML, CSS, and JavaScript.

No frameworks, no libraries, no external backend, and no CSS variables—everything runs client-side with persistent storage powered by the browser's `localStorage`.

## Features

- **Energy Balance Gauge**: Real-time visualization of calories consumed vs. remaining target, with over-budget alerts.
- **Macro Tracking**: Dynamic progress bars and gram targets for Protein, Carbohydrates, and Fats.
- **Date Navigation**: Browse past logs, jump to any calendar date, or view today's entries.
- **Meal Categorization**: Log food items under Breakfast, Lunch, Dinner, or Snacks & Drinks with serving notes and macro breakdowns.
- **Quick Food Presets**: One-click shortcuts for commonly tracked meals and ingredients.
- **Water Hydration Counter**: Interactive visual glasses counter tracking daily hydration (250ml per glass).
- **7-Day Trend Chart**: Pure vanilla bar chart showing intake against daily targets over the last 7 days.
- **Customizable Targets**: Adjust daily calorie, water, and macro goals with a 1-click auto-split calculator (30% Protein / 45% Carbs / 25% Fat).
- **Data Export & Import**: Backup your entire tracking history to a `.json` file and restore it on any browser.

## Tech Stack

- **HTML5**: Semantic structure and accessible modal dialogs.
- **CSS3**: Clean, responsive layout with custom design (no Tailwind, no CSS custom properties/variables).
- **JavaScript (ES6+)**: Zero external dependencies; data persistence using `localStorage`.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start logging your meals!
